El Problema

📋 Contexto Clínico

La apoptosis (muerte celular programada) es un mecanismo clave para eliminar células dañadas. En el cáncer, este mecanismo falla y las células cancerosas evaden la muerte.

🧪 El Kit ARY009

El Proteome Profiler Human Apoptosis Array de R&D Systems mide simultáneamente 35 proteínas relacionadas con apoptosis en una sola membrana.

⏱️ El Desafío

El análisis manual de las membranas es lento, subjetivo y propenso a errores. Un investigador puede tardar horas en cuantificar una sola imagen.

💡 Nuestra Solución

Un pipeline automatizado basado en visión por computador que procesa, cuantifica e interpreta los resultados en segundos.

🧬

¿Qué es la Apoptosis?

⚔️ Proteínas Pro-Apoptóticas

ACTIVAN la muerte celular. Un buen tratamiento las hace SUBIR.

BaxBadCaspase-3Cytochrome cSMAC/DiabloTRAIL R1/DR4p53

🛡️ Proteínas Anti-Apoptóticas

BLOQUEAN la muerte celular. Un buen tratamiento las hace BAJAR.

Bcl-2Bcl-xSurvivinXIAPcIAP-1HSP70Livin

El balance entre estas dos familias determina si la célula vive o muere. Nuestro sistema mide este balance automáticamente.

📐 Grilla 5×24

Cada tirilla tiene 5 columnas (A-E) y 24 filas. Las proteínas están en duplicado (pares verticales) para validación interna.

📍 Reference Spots

3 pares de puntos de referencia en las esquinas (A1-A2, A23-A24, E1-E2) para normalización inter-membrana.

🔲 PBS (Fondo)

Control negativo en D23-D24. Se resta como línea base para eliminar el ruido de fondo del array.

🔍 Detección de Spots — Black-Hat

Transformación morfológica que aísla puntos oscuros sobre fondo claro, inmune a sombras globales. Multi-escala (kernels 11-23px) para capturar spots de todos los tamaños.

📏 Anclaje Geométrico

Los Reference Spots sirven como anclas para construir la grilla. Se usa interpolación bilineal + corrección trapezoidal para manejar curvatura de membrana.

🧠 Algoritmos Clave

🎯 Safe Snapping Iterativo

Mean-shift local de 3 pasadas con ROI decreciente:
Pasada 1: ROI amplio (1.2×) — atrae spots lejanos
Pasada 2: ROI medio (0.85×) — refina posición
Pasada 3: ROI fino (0.55×) — centra con precisión
Aplica clamping estricto para que los cuadros no migren entre columnas.

🔄 ICP (Iterative Closest Point)

Alineación afín (rotación + traslación + escala) de la grilla a los spots reales detectados. Usa RANSAC para robustez, con safeguards: escala 0.85-1.15×, rotación máx ±15°.

📊 Cuantificación

1. Restar fondo PBS (control negativo)
2. Normalizar por Reference Spots
3. Promediar réplicas internas (2 strips)
4. Fold Change = Tratamiento / Control
5. Propagación de error: σ_FC/FC = √((σ_T/T)² + (σ_C/C)²)

🏷️ Separación Dual de Strips

Estrategia 1: Contraste de brillo (membrana gris vs fondo blanco) con Otsu + cierre morfológico.
Estrategia 2: Black-Hat para aislar solo spots oscuros como fallback.

🖥️ Interfaz Gráfica

4 pestañas integradas en una GUI moderna con CustomTkinter + Matplotlib

📋 Pestaña: Reporte

Tabla completa con intensidades Control vs Tratamiento, fold change, barras de error y estado de cada proteína. Clasificación automática por tipo biológico.

🧬 Pestaña: Interpretación

Explicación en español con puntaje apoptótico, balance Bax/Bcl-2, hallazgos principales y veredicto clínico orientativo. Incluye notas sobre limitaciones estadísticas.

📊 Pestaña: Gráficos

Barras horizontales estilo paper científico. Panel A: pro-apoptóticas. Panel C: anti-apoptóticas. Con error bars y p-valores aproximados (Welch t-test).

🗺️ Pestaña: Mapa Visual

Visualización de lo que el programa "ve" sobre cada tirilla. Cuadros de muestreo con colores por tipo y estilo por calidad (sólido vs punteado). Modo manual para ajustar referencias.
